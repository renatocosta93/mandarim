🧩 Lógica dos Ideogramas (Radicais)
Os caracteres chineses são blocos visuais lógicos com pistas de significado e som:
妈 = 女 + 马
mā = nǚ + mǎ
女 (Mulher) dá o sentido.
马 (Cavalo) dá o som aproximado!
好 = 女 + 子
hǎo = nǚ + zǐ
Mulher + Criança juntos
representam "Bom / Harmonia".
